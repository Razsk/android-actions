# Native Android Tech Stack & Clean MVVM Architecture

We decided to adopt Jetpack Compose with Material 3 for the UI, Room for local data persistence, Kotlin Coroutines + Flow for reactive data streams, WorkManager/AlarmManager for routine notifications, and MediaPipe LLM Inference SDK for on-device Gemma 2B execution. Architecture follows Clean Architecture + MVVM layer separation (Data, Domain, UI).
